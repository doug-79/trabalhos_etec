# 📊 Pesquisa de Satisfação de Atendimento - TudoWeb

Este projeto consiste em um programa em Python desenvolvido para automatizar a coleta e tabulação de dados de uma pesquisa de opinião de satisfação de clientes para a empresa de marketing **TudoWeb**.

## 📝 Descrição do Desafio

O objetivo é coletar o feedback de **50 entrevistados** sobre o grau de satisfação no atendimento prestado, armazenando e exibindo os resultados ao final.

A escala de avaliação utilizada é:
- **1:** EXCELENTE
- **2:** BOM
- **3:** RUIM

Ao término das entrevistas, o programa exibe na tela o total acumulado de cada um dos parâmetros avaliados.
